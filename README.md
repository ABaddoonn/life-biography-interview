# 人生传记与口述史采访

一个用于人生传记、长者口述史与家族回忆录的 Hermes Skill。先说明并获准建立本地档案，再梳理人生全貌、选择故事深入；边聊边反馈，按轮收尾，整理时间线与书稿。尊重受访者的隐私，避免编造记忆、原话和场景。

## 使用

安装后对助手说：“使用人生传记 Skill，采访我。”也可以提供已有访谈记录，让它接着整理或写稿，不必重新问一遍。

流程：**说明并获准本地存档 → 确定范围 → 梳理人生阶段并反馈 → 补充关键故事 → 整理时间线与章节 → 对照原文成稿。**

未指定时，本轮概览先安排约 30 分钟、5–8 个主问题，含追问和澄清最多 12 个问题；任一上限达到就先收尾。这是整轮的默认安排，不是每个阶段各问这么多，也不必问满；不是行业标准，不保证一轮写完完整传记。想不起来、不想讲的部分可以跳过。短版和完整传记按材料与本人意愿分别安排，不无限延长采访。

## v1.3.2 更新

- 不凑最低题数，以充分理解用户的需求、目标及已有材料为准。“95%信心”是主观目标，不是测得的准确率；理解需求不等于材料已经足够写完整一生。
- 聊完一段、出现转折或准备换主题时，反馈听懂的内容与有依据的联系；不只复述最后一句，也不每次强行接一道问题。
- 联系不同阶段和环境中的具体经历，下一问有来由，不做隐藏心理或人格判断。
- 正式访谈前说明保存位置和内容，征得同意后帮用户建立私人文件夹；保存原始问答、纠正与进度，新会话先读档再继续。
- 增加6组明确标为虚构的对照示例，说明自然访谈与忠实改稿的尺度；增加对应检查场景。
- 成稿保留原始依据，检查新增事实、因果、对白和模糊记忆，不能为了顺畅而补造内容。

## 本地记录与换会话继续

用户同意后，助手在约定的私人文件夹中维护 `访谈记录.md` 和 `访谈进度.md`。收到回答后保存相关内容，暂停时记下停点；新会话指明原文件夹，例如：

> 使用人生传记 Skill，读取我指定的访谈档案文件夹，从上次停下的地方继续。

这依赖助手具备文件读写工具及用户许可，不是安装后自动运行的后台程序。没有权限或无法访问原目录时，应明确说明，并提供手动指引或接续卡；只能从最后成功保存的位置恢复。换电脑需要复制档案或提供可访问路径。

私人档案不放进公开仓库、Skill 安装目录或全局记忆，不自动导入所有旧聊天。本仓库只包含通用规则和虚构示例，没有真实访谈。

## v1.2.0 改进

- 每次提问围绕一个阶段或事件，先从整段回答提取全部线索，不把每条事实拆成一道题。
- 能忠实复述主要经历、关键疑点已处理，就转到下一阶段；只缺普通细节不继续追问。
- 不用未经验证的“95%准确率”冒充掌握程度，分别记录可写、有关键疑点和材料有限。
- 回答困难时用已知事件缩小范围，必要时借助本人愿意提供的旧材料；不强迫连续回忆。

## v1.1.0 改进

- 先搭人生全貌，不再默认从模糊的幼年记忆开始。
- 已答过不重复问；听不懂就换简单问法，仍不懂则跳过。
- 同一故事只补必要细节，不逐件盘问日常杂事。
- 接受纠正并更新记录，不把推断写成用户经历。
- 明确每轮上限与阶段成果，用户询问耗时或疲倦时先停下来。
- 公开仓库只保存通用方法和虚构检查场景，不保存私人访谈。

## 安装

安装到 Hermes：

```bash
hermes skills install ABaddoonn/life-biography-interview/skills/life-biography-interview
```

也可以在 GitHub 页面选择 **Code → Download ZIP**，下载后将 `life-biography-interview` 文件夹放入 Hermes 的 `skills/communication/` 目录。

## 内容

本仓库只包含一个 Skill：

- `skills/life-biography-interview/SKILL.md`
- `skills/life-biography-interview/references/local-records.md`：说明、许可、本地保存与新会话接续
- `skills/life-biography-interview/references/examples.md`：虚构访谈及原文与整理稿对照示例、方法来源
- `skills/life-biography-interview/references/interview-checks.md`：虚构回归场景及检查要求
